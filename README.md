# retina-ai-screening

Open-source AI tools for early detection of retinal diseases and
for supporting the diagnosis and treatment of refractive errors
and amblyopia in children.

> **Status:** early stage / work in progress.

## Goals
- Detect retinal diseases early from fundus images
- Support screening of refractive errors in children
- Help reduce the risk of amblyopia (lazy eye) through earlier detection

## Planned roadmap
- [ ] Review public datasets and literature
- [ ] Data preprocessing pipeline
- [ ] Baseline classification model
- [ ] Evaluation and documentation

## Data
Only public, anonymized datasets are used. No real patient data
is stored in this repository.

## Disclaimer
This project is for research and education. It is not a medical
device and must not replace diagnosis by a qualified doctor.
